Portfolio

API & Website Monitor

Cadastre URLs, um worker bate nelas no intervalo que você definiu, e o dashboard mostra status, latência, histórico e incidentes. Alerta por e-mail, Discord ou webhook quando o serviço cai — e quando volta.

Bun Hono PostgreSQL Drizzle React + Vite coss UI

Monitores

Nome, URL, método HTTP, intervalo, timeout e status esperado.

Worker

Processo separado. Check periódico, incidente aberto no down e fechado no up.

Alertas

E-mail (SMTP opcional), webhook do Discord ou POST genérico.

Como rodar

cp .env.example .env
docker compose up -d --build

Dashboard em http://localhost:5173 · API em http://localhost:3000
